# 咸鱼突刺 · 心率直播叠层

把蓝牙心率实时叠到直播画面上：一条红线横穿、一只背矛的像素咸鱼、一个大号心率数字。
颜色**如实反映强度**，额外的动画负责**节目效果** —— 两者分开，不靠伪造心率。

数据源：标准 BLE 心率广播（GATT `0x180D` / `0x2A37`），当前配对 **BLE 心率设备 HR-210**（`AA:BB:CC:DD:EE:FF`）。

---

## 一、用之前：手环要开心率广播

手环 → **设置 → 心率广播**（或进「锻炼」开始一个运动），保持亮屏。
手环退出广播后画面显示 `---` 并转红点，**不用重启服务**，重新开广播会自动接回。

## 五、算法（冻结版）

### 颜色通道：诚实

```
B   = 个人基准，开播头 3 分钟锁定后不再漂移（或点控制台「校准基准」手动锁定）
P90 = 最近 10 分钟第 90 百分位心率
R   = clamp(P90 − p90Offset,  B + minGap,  B + maxGap)   ← 满红阈值，15 秒时间常数缓慢跟随

白 = B     黄 = B + (R−B)×0.4     橙 = B + (R−B)×0.7     红 = R
```

- 用 **P90** 而不是最大值：反映"最近的强度水平"，不被一次偶发尖峰锁死
- `B + minGap` = **防假红**；`B + maxGap` = **防抗红**
- **B 必须在开播时锁定**：实测中用过"全场累计 min/avg"当基准，结果开播初期样本少、min 偏高
  → B 偏高 → R 被顶到 114，而本人峰值只有 104，**永远差一口气红不了**
- 强度走 **Attack(2s) / Release(6s)**：上色快、褪色慢，画面不闪

### 特效通道：节目效果（与颜色完全独立）

```
30 秒内上涨 ≥ burstRise(10) bpm，且当前 ≥ B + burstAbove(15)
→ 触发约 1 秒的"心跳爆发"：数字提亮 + 咸鱼猛突刺
冷却 burstCooldown(30) 秒
```

**即使心率绝对值不高，突发紧张也有反馈**，而且不会污染颜色通道。

### 四个保护

| 保护 | 做法 |
|---|---|
| 传感器误差 | **不做滤波**（HR-210 读数可靠，避免引入延迟） |
| 颜色抖动 | Attack / Release 双时间常数 |
| 满红误触发 | 连续达阈值 `redHold`(2s) 才算满红，回落 `redDrop`(5) 解除（迟滞） |
| 数据断开 | 超过 `offlineAfter`(5s) 没新数据 → 显示 `---` + 红点，不沿用旧值 |

## 六、参数怎么调

**方式一（推荐）**：图形控制台 → 拖滑杆 → 「保存参数」
**方式二**：打开 `http://127.0.0.1:8080/tune` → 拖滑杆看实时预览 → 「保存到服务端」
**方式三**：`/tune` 里「复制参数」拿到 `?minGap=22&...`，贴到 OBS 浏览器源地址后面（URL 参数优先级最高）

| 参数 | 默认 | 作用 |
|---|---|---|
| `minGap` | **22** | R 至少比基准高多少（**调小 → 更容易红**，但可能假红） |
| `maxGap` | **30** | R 最多比基准高多少（防抗红；曾用 45，实测让 R 顶到 114） |
| `p90Offset` | 3 | R = P90 − 该值 |
| `anchorTau` | 15 | 阈值跟随速度（秒） |
| `attack` / `release` | 2 / 6 | 上色 / 褪色时间常数（秒） |
| `redHold` / `redDrop` | 2 / 5 | 满红迟滞 |
| `offlineAfter` | 5 | 多久没数据算离线（秒） |
| `burstRise` | 10 | 窗口内涨多少触发特效 |
| `burstAbove` | 15 | 且要高于基准多少 |
| `burstWindow` | 30 | 涨幅观察窗口（秒） |
| `burstCooldown` | 30 | 特效冷却（秒） |

## 七、用真实记录验收

控制台网页里**点一行记录**就能回放（走 `/replay` 接口）；命令行等价于：

```bash
python replay_check.py logs/heart-rate-YYYYmmdd-HHMMSS.csv   # 三个指标
python tune_scan.py    logs/heart-rate-YYYYmmdd-HHMMSS.csv   # 参数扫描对比
```

输出：
- **节目效果**：满红次数、突发特效次数（换算成"每 10 分钟几次"）
- **真实性**：平静期假红次数
- **稳定性**：阈值最大跳变、R 的波动范围
- **阈值诊断**：有多少个采样点站在阈值之上、最长连续多久（判断"是不是差一口气"）

**实测判读**：

| 结果 | 怎么办 |
|---|---|
| 满红 0~0.5 次/10min | 不够刺激 → `minGap` 降到 18~20 |
| 满红 1~2 次/10min + 假红 0 | 冻结这套参数 |
| 出现平静期假红 | 提高 `minGap`，或把 `redHold` 调到 3~4 秒 |
| 阈值诊断显示"最长连续 0.0 秒" | 说明峰值根本没碰到阈值 → 查 B 是否锁高了 |

## 九、常见问题

**画面显示 `---`**
手环退出广播了 → 重新开启；或服务没启动 → 开图形控制台点「启动心率服务」。

**一直不满红**
先看控制台的锚点行：如果 `10分P90` 远低于 `基准 + minGap`，说明这段确实没到强度 → 调小 `minGap`。
如果**基准 B 明显高于你的平静心率**，点「校准基准」重锁。

**颜色一闪一闪**
调大 `release`（褪色更慢）或 `redHold`（满红迟滞）。

**改了参数没生效**
要「保存参数」，且**网页需刷新**、**悬浮窗需重启**才读取新值。

**悬浮窗不见了**
删掉 `hud.json` 再启动，会回到屏幕右上角。
