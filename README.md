# 咸鱼突刺 · 一键总控

总控已更新为低饱和像素风。首次更新后按F5载入；入口及已保存的比例保持。设计与本轮验证见 [DESIGN.md](DESIGN.md) 和 [DESIGN_VERIFICATION.md](DESIGN_VERIFICATION.md)。

**双击根目录的 `一键打开咸鱼总控.vbs`。** 不需要分别打开桌面GUI、effects页面或悬浮窗。Windows入口自动寻找已安装Python，不要求pythonw在PATH中；启动失败会显示提示，日志在runtime目录。

**想同时打开桌面悬浮窗：双击 `一键开播（总控+悬浮窗）.vbs`。** 它复用同一服务、总控与受管悬浮窗，重复点击不会再多开一个。OBS浏览器来源继续读取同一个服务；此入口不启动OBS程序或录制。

## 连接你自己的心率设备

在顶部展开「连接心率设备」，点击「扫描附近设备」，再点自己的设备旁的「连接」。也可打开 `http://127.0.0.1:8080/devices`。
支持开放标准BLE心率广播的手表及心率带；无需改脚本或手工填地址。每个人在自己的电脑运行，一次选择一台设备。
首次连接成功会记住；断线只重连所选设备；手动断开后暂停自动连接。切换设备重置当前基准与统计，旧CSV保留。
完整操作、分享与故障排查见 [BLUETOOTH_GUIDE.md](BLUETOOTH_GUIDE.md)。

悬浮窗右键菜单第一项「隐藏桌面悬浮窗（直播继续）」仅关闭桌面窗口，OBS和心率服务保持。恢复时在总控点「显示悬浮窗」，或再次双击原一键开播VBS；窗口位置会保存。

总控只有三个入口：

- **直播总控**：看真实画面、选皮肤、调大小、开关悬浮窗、复制OBS地址。先预览，再点“应用到直播”。
- **试效果**：在同一窗口模拟心率、触发突刺、检查八种姿态；不改正式心率。
- **更多工具**：历史回放、高级参数和行为验收，按需在本窗口展开。

“角色与画面”里提供两种**心率线布局**：**背景穿插**（默认，曲线铺满背景，鱼和数字盖在线上）与**曲线在下**（鱼和数字在上，曲线独立放下方）。选择先预览，点击“应用到直播”后保存并同步OBS和桌面悬浮窗；更换布局不会多开进程。已有OBS来源升级后需刷新一次。URL可用`?traceLayout=overlay`或`?traceLayout=lower`固定布局，显式URL继续优先。

## 三个标签与按钮

- **直播总控**：真实预览在左，外观及输出位置在右；调节后应用当前画面。预览固定时不再覆盖下面的按钮。
- **试效果**：模拟心率、突刺、自动演示和八姿态控件立即在预览旁显示；窄屏会滚到对应操作区。切换OBS/桌面预览保留当前固定姿态；不会向正式直播写模拟心率。
- **更多工具**：立即打开历史与数据，也可直接切换高级参数/行为验收；回到其他标签会卸载工具页面。左右箭头、Home/End可切换标签。
- 保存、复制、校准、连接等操作的失败原因会在屏幕底部显示；提示不拦截点击。断线保留草稿，重连恢复；服务重启会更新控制凭证，结束后重新一键开播也能让已打开的新版页面恢复按钮。

首次更新后刷新当前总控一次，加载新布局与逻辑。源程序、原一键VBS、素材宽度默认150%不变。

## 鱼图偏宽，怎么压窄

总控 → **调外观 → 素材宽窄（只改鱼图）**。往左压窄、往右拉宽，范围50%–150%，用户选定默认值为**150%**；可点“默认150%”回到该选择，或直接点**偏瘦75%**，或**恢复原始比例**回到100%。仅红巾咸鱼素材启用此项。

高度、数字、窗口宽高不变；先看实时预览，再点**应用当前画面到直播**，悬浮窗与OBS一起变化并保存。原始PNG不会被重画或覆盖。显示空间不足时宽度会受限，增加窗口宽度即可。普通“角色大小”滑块仍用于整体等比放大缩小。

## 所有调整从可视化总控进入

一键入口仍为`G:\downloads\heart-rate\一键开播（总控+悬浮窗）.vbs`。

1. 预览区选择**桌面悬浮窗**，在下面调整宽高、右侧调整角色/皮肤/布局；画布宽高和预览百分比明确显示。缩略预览可点**原始尺寸1:1**查看网页像素原始大小，超出区域可滚动；系统和浏览器缩放仍会影响屏幕物理大小。
2. 点击预览下方**应用当前画面到直播**，或尺寸区**应用当前画面（尺寸＋外观）**，均提交当前所有外观与尺寸草稿。旧版“只提交宽高但留下角色草稿”的行为已移除。
3. **显示悬浮窗边界 / 拖角调整**会在实际悬浮窗显示编辑底板、边框与右下角，拖动松手保存；完成时再次点击按钮。主体左键仍移动位置。也可用原生右键进入编辑模式。
4. 右键悬浮窗 → **大小与外观（可视化总控）**，复用同一个总控并聚焦桌面预览；不再另开一套无预览滑块窗。右键换肤仍写共享配置，OBS及总控跟随。
5. **更多工具 → 高级参数**仍在总控中，主画面预览保持可见；宽屏时预览卡片随滚动固定。

角色可调**50%–400%**，HUD宽160–1920、高64–1080；五档240×104、312×102、416×136、640×280、960×420。超出可用空间时等比容纳，并明确提示增大窗口。OBS画布分别设置，皮肤、倍率、心率线布局与特效共享。总控复制的OBS根地址不会固定皮肤。

网页与原生调用同一个布局函数；八张咸鱼图的精确缩放结果共用。对照验证覆盖三画布、两倍率、两布局及三姿态共36组，Tk图像与浏览器Canvas鱼图RGBA哈希一致。这不代表整个画面及动画相位逐帧一致：心率线栅格化、暖色叠加、心跳与突刺相位仍各自绘制。

原总控入口按需打开桌面悬浮窗，“一键开播（总控+悬浮窗）.vbs”会同时打开。后台心率服务由总控管理，重复启动会复用；右上角“结束本次运行”同时关闭服务和它持有的悬浮窗。关闭浏览器窗口会保留OBS数据，需停止时请使用结束按钮或stop-heartrate.bat。

OBS浏览器来源仍用 `http://127.0.0.1:8080/`，默认520×170。首次在OBS添加一次即可；本程序不另启OBS进程。URL若显式固定skin或参数，仍优先于总控保存值。若升级前OBS已打开，请首次刷新来源，加载新版绘制代码。

## 大小稳定性修复

现使用用户提供的`fish_states_8png.zip`八张独立PNG，按冷静、好奇、专注、紧张、慌张、蓄力、突刺、收招映射。PNG逐字节原样保留，均为576×384 RGBA；frames.json统一使用(288,224)鱼身锚点，不再套用旧图的逐张偏移。心跳不缩放图像；开启时只有小幅整像素位移，关闭后没有常驻漂浮。素材自带水花和残影，不再额外叠同类程序特效；原版像素鱼的特效保留。不同姿态的局部像素与轮廓仍可能变化，不承诺连续逐帧动画级别的完全一致。所有皮肤的大小滑杆均生效。

心率P90、Attack/Release、满红迟滞和burst判据继续沿用上一合并版；基准仍用P25慢跟随，六档仍有绝对BPM迟滞；真实姿态档位由服务端统一下发，新窗口不再从0各算各的。改动详见 [BUG_AUDIT.md](BUG_AUDIT.md)。

## 运行与升级

Windows + Python3.10以上（含tkinter），依赖仅 `bleak`、`aiohttp`。旧参数、devices.json、hud.json、logs/全部保留。启动脚本的旧名称只是统一入口的兼容别名；停止脚本不再按所有同名Python进程批量终止。

已有旧版占用8080时，新入口会明确提示，不会偷偷另开端口让OBS继续连接旧版。升级与回退见 [DEPLOY.md](DEPLOY.md)，自检结果见 [VERIFICATION.md](VERIFICATION.md)。

`/effects` 会转到 `/console#effects`；`/monitor`、`/tune`、`/test` 保留高级兼容路由。生产服务不提供合成数据入口。参数文件及原始心率记录不包含在发行包中。

开发验证：`python -m unittest discover -s tests -v`。可选可见Chrome与原生Tk检查见 [tests/README.md](tests/README.md)。

## 改动时保留的约束

pixel.html仍有两个独立内联script，TEST_MODE及RAF启动行在第二块；TEST模式不重复调度frame。heartrate_hud.py的幽灵取整、1px量化、_span半像素区间、_pix_rect保持原实现。/assets保留is_dir守卫。BAT使用GBK/936/CRLF，VBS使用UTF-16，均不可直接默认UTF-8重存。
